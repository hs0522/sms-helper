## 마래푸 문자 도우미 — 윈도우 미니 위젯

윈도우 바탕화면에서 항상 위에 띄워 두고 쓰는 컴팩트 위젯입니다.

- **크기** 420×760 (최소 380×620) · 마지막 위치·크기 그대로 열림
- **상단 바** 드래그 이동 · `📌` 항상 위 고정 · `—` 최소화 · `×` 닫기
- **복사하기** 윈도우 클립보드로 바로 복사 (`문자 앱 열기`는 복사 후 붙여넣기 안내)
- **자동 업데이트 확인** 실행할 때 `widget-v*` 새 버전이 있으면 `업데이트` 버튼
- **웹·폰과 같은 화면** 웹 앱 v1.4.10 자산을 그대로 내장 — 오프라인에서도 열림

### 받는 파일

- `MaraepuSmsHelper-Setup.exe` — 설치판 (바탕화면 바로가기)
- `MaraepuSmsHelper-Windows.zip` — 설치 없이 실행하는 포터블판

윈도우 11에는 Microsoft Edge WebView2가 기본으로 들어 있어 따로 설치할 것이 없습니다.
