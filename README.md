업무 문자 17종을 골라 값만 채우고 바로 복사하는 웹 앱입니다. PC(브라우저)와 아이폰(사파리)에서 같은 파일로 동작합니다.
**내 문구를 직접 만들어 쓰고, 기존 17종 문구도 영구 수정**할 수 있으며, **PC·폰(GitHub 비공개 Gist) 자동 동기화**로 내 정보·연락처·즐겨찾기·문구를 기기끼리 맞춥니다.

- 만든 기준: `downloads/마래푸중앙부동산_문자템플릿_정리.md` (업무 카테고리 4개) → 2026-11-26 피드백으로 문구를 합쳐 **17종**
- 글꼴: Freesentation (앱 안에 파일로 포함 · 오프라인에서도 동일)
- 화면: 밝은 라이트 톤(`#F6F7FB` · `#FFFFFF` · 인디고 `#5B5FE9`) · 컬러 이모지 대신 **SVG 라인 아이콘**(`js/icons.js`)
- PC에서는 **컴팩트 위젯 크기**(최대 1040 × 700, 가운데 정렬)로 놓입니다 — 1440 모니터에서도 넓게 퍼지지 않고, 작은 창(1000×720)에서도 빈 여백 없이 딱 맞습니다
- **끝선 통일**: 상단 바(제목 ~ 내 정보 설정)의 좌우 끝선이 3단 패널의 좌우 끝선과 같고, 패널 안쪽의 제목·라벨·입력칸·버튼은 모두 `14px` 한 선에서 시작합니다(모바일에서는 `12px` 화면 여백).
- **군더더기 없는 머리**: 왼쪽 목록은 검색창 바로 아래 즐겨찾기·카테고리가 이어지고(필터 칩·`전체 문자 · 20개` 없음), 가운데 편집 패널은 제목만 보여 줍니다(부제목 없음, 제목과 `비우기` 버튼은 세로 가운데 정렬).
- **모든 문자 맨 아래에 상호·번호 서명 고정** — `마래푸중앙부동산 드림` / `010-4585-7365 / 02-312-7365` (1번만 `대표 황호선 드림`), 켜고 끄는 토글 없음
- 아이폰 **홈 화면에 추가** 시 전체화면 앱처럼 실행(PWA: `manifest.webmanifest` + 애플 메타)
- 구성: **문자 작성 + 중개보수 계산기** 전용 (매물 찾기·진행 거래 탭은 덜어냈습니다 — 그 일은 `매물 스파이더`가 맡습니다)
- 외부 라이브러리 없음 — CDN도, 엑셀 파서도 쓰지 않아 `file://` 더블클릭·비행기 모드에서 그대로 동작합니다

## 바로 열기

**PC** — `index.html`을 더블클릭해도 열립니다. 로컬 서버로 열려면:

```bash
cd projects/sms-helper
python3 -m http.server 8000
# 브라우저에서 http://127.0.0.1:8000/index.html
```

**아이폰** — 웹 주소로 열고 사파리 공유 → **홈 화면에 추가**를 하면 앱처럼 실행됩니다(주소 표시줄 없이 전체 화면).

- 이름은 `문자도우미`, 아이콘은 보라 말풍선(`icons/icon-180.png`), 상태 표시줄은 기본(`default`)
- `manifest.webmanifest`(standalone · 테마 `#4f46e5` · 192/512/maskable 아이콘)와 애플 메타가 들어 있어 별도 설정 없이 동작합니다
- 모든 경로가 상대경로(`./`, `icons/…`, `js/…`)이고 외부 CDN·서버가 없어, 나중에 안드로이드 `.apk`(Capacitor/TWA)로 쌀 때 `webDir`에 이 폴더를 그대로 넣으면 됩니다

### 안드로이드 앱(.apk)

- 웹 화면 전체(HTML·CSS·JS·폰트)를 앱 안에 넣은 **WebView 껍데기**입니다 — 인터넷 없이도 열립니다.
- `문자 앱 열기`는 안드로이드 기본 문자 앱을 본문이 채워진 채로 엽니다(`sms:?body=` 변환). `문자 전체 복사하기`는 클립보드 API → `execCommand` → 앱 복사 통로 순서로 동작합니다.
- 입력값·설정은 앱 안 저장소에 남습니다(웹 버전과 별도). 웹·앱 사이는 `내 정보 설정 → PC·폰 자동 동기화`로 맞춥니다.
- 설치: 내려받은 `.apk`를 열고 《출처를 알 수 없는 앱 허용》 후 설치. 새 버전을 덮어 설치하려면 같은 서명 키가 필요해 `android/keystore/debug.keystore`(디버그 전용 키)를 저장소에 함께 두었습니다.
- 다시 빌드(로컬): JDK 17 + Android SDK(platform 34 · build-tools 34.0.0)에서

```bash
cd android
echo "sdk.dir=$ANDROID_HOME" > local.properties
gradle assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

> GitHub Actions 워크플로우(`.github/workflows-disabled/android-apk.yml`)는 준비해 두었지만, 피클의 GitHub 연결에 `workflows` 권한이 없어 저장소에 올릴 수 없었습니다. GitHub 웹에서 `.github/workflows/`로 옮겨 두면 태그(`v*`)를 밀 때 자동으로 APK를 빌드해 릴리즈에 붙습니다.

| 상단 | 제목 · 카테고리 탭(전체 / 고객 응대·매물 관리 / 집보기·방문 안내 / 약정·계약 진행 / 잔금·사후관리) · 내 정보 설정 |

| 오른쪽 | **미리보기**(직접 수정 가능) · 글자 수 · **문자 전체 복사하기** |

- **폰에서 목록 고르기**: 상단 카테고리 탭을 누르면 그 카테고리(5/5/4/3)의 첫 문자로 넘어가고 목록 시트가 바로 열립니다. `목록` 버튼은 고른 카테고리와 상관없이 **전체 17종**을 보여 줍니다(상단 탭도 `전체`로 돌아감).

목록의 각 줄은 `아이콘 · 번호 · 제목 / 부제목`으로 보입니다. 번호는 예전 문자 번호(1~20)이고, 제목·부제목은 아래 표와 같습니다. `신규`·`고정 문자` 같은 표시는 없앴습니다.

## 자주 쓰는 기능

### 화면 다듬기

- **스낵바 + 되돌리기**: `비우기` · `원상복구` · 매물 줄 삭제 · 연락처 삭제 직후 아래에 5초 동안 `되돌리기`가 뜹니다.
- **인라인 안내**: 입력을 막지 않고 칸 아래에만 살짝 알려 줍니다 — 계좌번호가 너무 짧을 때, 월세에서 보증금이나 월세 한쪽만 넣었을 때, 동·호수 중 하나만 넣었을 때 등.
- **모바일 제스처**
  - 매물 줄(2번째부터)을 **왼쪽으로 밀면** 그 줄이 빠집니다(스낵바로 되돌리기 가능).
  - 문자 목록을 **0.55초 길게 누르면** ★ 즐겨찾기가 켜지고/꺼집니다.
- **키보드가 열리면 하단 바는 사라집니다**: 아이폰에서 숫자·문자 키보드가 올라온 채로 스크롤하면 `문자 앱 열기 / 복사하기` 바가 화면 가운데에 떠 `미리보기` 카드를 가르던 문제를 고쳤습니다. 입력칸에 초점이 가 있거나 화면 보이는 높이(`visualViewport`)가 줄어든 동안에는 `body.kbd-open`으로 바를 감추고, 초점을 빼면 다시 나타납니다.
- **직접 수정**: 미리보기 칸은 그대로 타이핑해서 고칠 수 있고, `원상복구`로 입력값 기준 문구로 되돌립니다.
- **저장**: 상호·연락처·중개보수 계좌·각 문자 입력값·수정한 본문·즐겨찾기·협력업체 연락처·내 문구·영구 수정 문구가 그 브라우저(localStorage)에만 저장됩니다. 서버로 보내지 않습니다. 내부 ID(`t1`~`t20`)와 예전 저장값은 그대로 읽습니다.

### 내 문구 추가 · 기존 문구 영구 수정

- **새 문구 추가**: 왼쪽 목록 맨 위(모바일은 `목록` 시트 안) `+ 새 문구 추가` → 카테고리·제목·부제목(선택)·본문을 적고 저장합니다. 하단에 `상호 / 연락처` 서명을 넣을지 고를 수 있고(기본 ON), 저장하면 목록에 `내 문구` 배지와 함께 바로 나옵니다. 목록 아이콘은 기본 말풍선 라인 아이콘입니다.
- **내 문구는 언제든 편집·삭제**: 그 문구를 고른 뒤 미리보기 머리의 `문구 편집` → 고치거나 `삭제`(확인 후, 스낵바로 되돌리기). 다른 기기로도 백업·동기화에 함께 실립니다.
- **기존 문구 영구 수정**: 같은 `문구 편집`을 누르면 `문구 편집 — 영구 저장` 창이 열립니다. 지금 화면의 본문(서명은 뺀 상태)이 들어 있고, 고쳐서 저장하면 그 문구는 **고정 본문**으로 바뀌어 입력 항목 대신 `영구 수정한 문구입니다` 안내가 뜹니다. 목록에는 `수정됨` 배지가 붙습니다.
- **기본값으로 되돌리기**: 영구 수정한 문구에서는 미리보기 머리에 `기본값으로`가 나타납니다. 누르면 원래 문구와 입력 항목이 그대로 돌아옵니다(스낵바 되돌리기 가능).
- **일회성 수정과 구분**: 미리보기 칸에서 바로 고친 것은 그 화면에서만 쓰는 일회성 수정(`원상복구`)이고, `문구 편집`은 계속 남는 영구 저장입니다. 일회성으로 고쳐 둔 본문을 `문구 편집`으로 열면 그 본문이 그대로 담겨 영구 저장할 수 있습니다.
- 문자 본문에 대괄호 `[ ]`는 나가지 않습니다 — 편집창에서 저장할 때 소괄호 `( )`로 바뀝니다.

### PC·폰 백업 · 자동 동기화

`내 정보 설정` 아래쪽 두 구역에서 합니다.

- **백업 · 불러오기 (설정 없이 바로)**
  - `내보내기 (복사)`: 내 정보(상호·연락처·계좌·금액 표시), 협력업체 연락처, 즐겨찾기, 내가 만든 문구·영구 수정 문구 전체를 JSON으로 클립보드에 복사합니다(카톡 나에게 보내기 등으로 옮기기). `파일로 저장`은 같은 내용을 `문자도우미_백업_YYYY-MM-DD.json` 파일로 내려받습니다.
  - `불러오기`: 붙여넣고 `불러오기 적용`, 또는 `파일 선택`으로 JSON 파일을 고르면 즉시 복원됩니다. 백업 파일에는 토큰·Gist ID가 들어가지 않습니다.
- **PC·폰 자동 동기화 (GitHub)**
  - GitHub 토큰(`gist` 권한)을 넣고 `연결 및 동기화`를 누르면 됩니다. `Gist ID`를 비워 두면 **비공개(Secret) Gist를 자동으로 만들어** 그 ID를 채워 둡니다. 이미 만든 Gist ID가 있으면 그걸 넣으면 됩니다(여러 기기가 같은 ID를 씁니다).
  - 연결된 뒤로는 앱을 열 때 최신 내용을 자동으로 받아 오고, 문구·연락처·설정이 바뀌면 잠시 뒤(2.5초) 자동으로 올립니다. 상단 오른쪽에 `동기화됨` / `저장 대기` / `동기화 중` / `오프라인` 표시가 뜨고, 누르면 설정이 열립니다.
  - 충돌은 `updatedAt` 타임스탬프로 정리합니다 — 더 최신인 쪽(다른 기기에서 방금 고친 것 또는 이 기기에서 방금 고친 것)이 남습니다.
  - 토큰과 Gist ID는 **오직 그 기기의 브라우저(localStorage)에만** 저장됩니다. 코드·저장소·백업 파일 어디에도 들어가지 않습니다. `연결 해제`를 누르면 이 기기에서 지웁니다.
  - 토큰 만들기: GitHub → Settings → Developer settings → Personal access tokens에서 `gist` 권한만 체크해 발급합니다.

### 매물 입력 (2·4·5·6·8번)

- 매물 한 줄마다 `매매` / `전세` / `월세`를 고르고 금액을 **만 원 단위**로 칩니다. `230000` → 칸 안 오른쪽에 `만원`, 바로 아래 줄에 `2,300,000,000원 (23억)`이 뜨고 문자에는 `(매매 23억)`으로 나갑니다. 좁은 칸에서는 환산 줄이 `2,300,000,000원` / `(23억)` 두 줄로 자연스럽게 나뉩니다.
- **매물 노출은 입력칸 안 배지로**: 매물 줄마다 단지명은 늘 그대로 나가고, **동 칸의 배지**로 `동` ↔ `단지`, **호 칸의 배지**로 `호` ↔ `층`을 바꿉니다. `208` → `208동` / `2단지`, `208` → `208호` / `2층`.
- **`단지`로 가려도 호수·층은 그대로 적을 수 있습니다**: 호수 칸이 잠기지 않고, `[호 ↔ 층]` 배지도 그대로 돌아갑니다. 호수 칸이 비어 있으면 `2단지`까지만, 값이 있으면 `2단지 1203호` / `2단지 12층`처럼 함께 나갑니다. 중개 문자에서 흔한 `마포래미안푸르지오 2단지 12층` 표기가 이 한 줄로 됩니다.
- **계약·잔금 서류(12·13·14·18번)는 동·호수를 그대로**: 이 템플릿에서는 전환 배지 없이 `404동 1903호`처럼 **동·호수 전체**가 나갑니다. 단지·층으로 가리는 표시는 매물 안내에서만 씁니다.
- **금액**: 입력은 만 원 단위(`27000` → 아래 줄 `270,000,000원 (2억 7천만)`). 문자 표기는 설정에서 `전체`(`270,000,000원 (2억 7천만 원)`) / `만원 단위`(`27,000만 원`) / `끊어읽기`(`2억7천만 원`) 중에 고릅니다. 예전 저장값(`won_eokman`·`won`·`eokman`·`won_eok`·`eok`)도 그대로 읽습니다.
- **거래유형과 금액은 한 줄**: `[매매] [전세] [월세]` 버튼 **바로 옆**에 금액 입력칸이 붙습니다(오른쪽 남는 폭을 다 씀). **월세**를 고르면 오른쪽 영역이 **정확히 반반(`1fr 1fr`)**으로 갈라져 `보증금`·`월세` 두 칸이 나란히 들어가고, 각 칸 아래에 `200,000,000원 (2억)` / `300,000원 (30만)` 환산이 따로 붙습니다. 390px 폰에서도 버튼과 두 칸이 한 줄이고 입력 글씨는 16px 그대로(아이폰 확대 없음)입니다. 375px 아래로 좁아지면 두 칸만 아래 줄로 내려 반씩 씁니다.
- **금액칸 모양은 매물 스파이더와 같습니다**: 숫자는 **왼쪽 정렬**, 단위 `만원`은 **입력칸 안쪽 오른쪽**, 환산(`원단위 (억·만)`)은 **입력칸 바로 아래 줄 왼쪽**. 문자에는 `(보증금 1억 / 월세 300만 원)`으로 조합됩니다. 매물 블록을 쓰는 2·4·5·8·11번 모두 같습니다. 비어 있을 때도 환산 줄 자리를 잡아 두어 화면이 들썩이지 않습니다.
- **계좌 자동 정리**: `국민 123456-01-234567 홍길동`, `홍길동 하나 12345678901234` 어느 순서로 붙여넣어도 `하나은행 12345678901234 홍길동`처럼 정리됩니다.

### 마래푸 동·호수 → 평형·타입·방향 자동 (11번 특가 매물 홍보)

- `마포래미안푸르지오_동호수_타입표.xlsx`(1~4단지 동·라인별 방향·타입·전용·공급)를 `js/maraepu-types.js` 표로 넣었습니다. **동 번호 + 호수 끝 두 자리(라인)** 로 찾습니다.
- 매물 단지명이 `마포래미안푸르지오`(또는 `마래푸`)이고 동·호수를 넣으면 매물 줄 아래 **`평형·타입·방향`** 칸이 자동으로 채워집니다 — 예: `205`동 `1203`호 → `34평 84E · 동향`. 평형은 공급면적을 3.3058로 나눠 반올림했습니다(84B 113㎡ → 34평).
- 문자에는 매물 줄 끝에 그대로 붙습니다: `🔑마포래미안푸르지오 205동 1203호 34평 84E · 동향`. `[단지]`로 가려도 안쪽 동·호수로 같은 값을 찾습니다(`2단지 12층 34평 84E · 동향`).
- 표에 없는 동·라인(임대 동 101·201·306·405 포함)이나 다른 단지는 비워 두고, **직접 적은 값이 이깁니다**(동·호수를 바꿔도 직접 고친 값은 그대로).
- **달력**: 날짜를 고르고 오전·오후/시·분을 선택합니다(분은 앱 어디서나 5분 단위 `00 · 05 · … · 55분`). 4번(간단형)은 `내일 11/26 (목) 오전 9시30분`, 그 밖에는 `2026년 11월 28일 토요일 오전 11시 30분` 꼴로 나갑니다. 12·13·14·18번 일정칸은 모두 같은 달력 아이콘과 같은 달력·시간 선택기를 씁니다.

### 지급 일정 표 (12번 매매조건·약정 / 18번 중도금·잔금)

매물 스파이더의 계약 입력 팝업과 같은 `구분 | 일정 | 금액` 표입니다. 표 박스 왼쪽 위에 `지급 일정` 섹션 라벨이 아래 `특약`과 같은 모양으로 붙습니다.

- 줄: **가계약금**(11번) · **계약금** · **중도금** · **잔금**. 줄마다 `[일정 📅]`과 `[금액 만원]`이 **한 줄**에 나란히 놓이고, 그 아래 줄에 원단위·억만 환산이 붙습니다.
- 왼쪽은 **구분 글자와 `%` 입력칸을 위아래로 바짝** 붙여 두고(행끼리 왼쪽 정렬), 오른쪽 일정·금액이 카드 오른쪽 끝까지 찹니다. `%`를 고치면 **나머지 금액의 그 비율**로 그 줄 금액이 다시 채워집니다.
- **일정 칸은 날짜가 통째로 보일 만큼 넓습니다** — `2026.11.28 (토)` 처럼 연·월·일과 요일, 지우기 `×`까지 잘리지 않고 들어갑니다(1000px 창에서도 126px).
- **잔금은 점선 칸으로 읽기 전용** — `매매대금(임대차는 보증금) − 계약금 − 중도금`. 중도금이 비면 0원으로 보고 계산합니다. 예) `675,000,000 − 67,500,000 − 512,500,000 = 95,000,000원`.
- **계약금·중도금의 `%`** 를 고치면 그 금액이 매매가 기준으로 다시 채워지고, 금액을 고치면 `%`가 따라옵니다. `매매가로 계약금·중도금 자동 계산`은 10% · 25%로 채웁니다.
- 표 아래 **총합계**(예: `2,470,000,000원 (24억 7천만원)`)만 보여 줍니다. 맞을 때는 안내 글자를 두지 않고, 계약금·중도금이 매매대금을 넘거나 음수가 들어오면 **빨간 경고**로 바뀌며 문자에는 잔금 자리에 `확인 필요`와 `※` 안내가 들어갑니다(음수 금액은 문자에 나가지 않습니다).
- 모바일(390px)에서는 `구분 + 일정` / `금액` 두 줄로 접혀 가로 넘침이 없습니다.

### 집보기 후 감사 인사 (9번)

- 대상 3가지마다 문구 7종이 들어 있습니다. `문구 교체`를 누를 때마다 `1 / 7` → `2 / 7` … 순서로 바뀌고, 7종을 다 돌면 처음으로 돌아옵니다.
- `안부 문구`에서 `추가 안 함 / 감기 조심 / 편안한 저녁 / 주말 잘 보내세요 / 좋은 하루` 중에 고르면 문구 아래에 한 줄 붙습니다.

### 전문가·협력업체 소개 (17번)

- 분야 6종: `대출` · `세무` · `법무사` · `인테리어` · `입주청소` · `이사업체`. 분야마다 도입 문구가 따로 있습니다.
- 처음 열면 연락처가 **비어 있습니다**(공개 저장소에 실제 연락처를 두지 않습니다). 아래 칸에서 분야별로 추가하면 이 기기에만 저장되고, 그다음부터는 자동으로 남아 있습니다.
- 목록에서 **체크한 상담사만** `[이름] … / [연락처] …` 블록으로 문자에 들어갑니다. 체크를 풀면 그 사람만 빠집니다.
- 목록 상자에는 **3명 높이**까지만 보이고, 4명부터는 그 상자 안에서만 스크롤됩니다(입력칸·미리보기는 그대로).
- 아래 칸에 이름과 전화번호를 넣고 `+ 연락처 추가`를 누르면 분야별로 저장됩니다(전화번호는 `010-1234-5678` 꼴로 정리). `×`로 지우면 스낵바 `되돌리기`로 되살릴 수 있습니다.

### 중개보수 계산기 (19번)

서울특별시 주택 중개보수 요율표(2021.10.19 시행) 기준입니다.

- 구간별 상한요율과 한도액, 월세 환산보증금(×100, 5천만 원 미만이면 ×70), 오피스텔(85㎡ 이하 주거용 매매 0.5%·임대 0.4% / 85㎡ 초과·업무용 0.9% 이내), 주택분양권(주택 매매 요율), 상가·토지(0.9%)를 적용합니다.
- **결과 박스와 `적용 요율 (%)` 이 한 줄에 나란히** 있고, 두 칸은 위에 `중개보수 합계` · `적용 요율` 라벨을 같은 모양으로 달고 **높이(`44px`)와 위아래 선이 정확히 같습니다**. 그 아래에 `중개보수(공급가액) · 부가세 · 상한 · 매물 종류` 계산식이 원단위 금액 표시처럼 작고 연한 글씨로 붙습니다.
- **협의 요율**을 넣으면 상한 안에서 깎아 계산하고, 상한을 넘는 값을 넣으면 경고와 함께 **상한요율로 계산**합니다.
- **부가세 기본값은 `간이 4%`** 입니다. `미포함(별도)` / `일반 10%`를 누르면 금액과 계산식이 바로 바뀝니다.
- 음수·빈 금액은 계산하지 않습니다.

## 매물 스파이더에서 값 넘겨 열기

`매물 스파이더`의 `문자 보내기`가 아래 주소로 이 앱을 열면, 해당 문자의 입력칸이 미리 채워집니다.

| --- | --- | --- |
| `template` | 열 문자 | `t1`~`t20` 또는 숫자(`7`). 이름도 됩니다: `property`(8번) `owner`(4번) `coagent`(5번) `reservation`(6번) `parking`(7번) `contract`(12번) `fee`(19번) `thanks`(9번) `promo`(11번) `vendor`(17번) |
